# Java Swing Applications

A collection of Java desktop applications built to practise object-oriented programming and GUI development using **Java Swing**.

## 🚀 Applications Included

- **Calculator** — Perform basic calculations.
- **Word Counter** — Count words in text.
- **IP Finder** — Explore IP-related utilities.
- **Tic-Tac-Toe** — Play a classic two-player game.
- **Puzzle Game** — Explore a simple puzzle application.
- **Character-Based Applications** — Practise desktop UI components.
- **Online Test** — An application related to test-taking.
- **Font Chooser** — Explore font selection in a GUI.

*The list is based on the repository description. Check the source code to confirm the exact features and application names.*

## 🛠️ Technologies

- Java
- Java Swing
- AWT (where used)

## 📁 Project Structure

The `JApps` directory contains the application source files.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in an IDE that supports Java, such as Eclipse or IntelliJ IDEA.
3. Inspect the source files and identify the application you want to run.
4. Configure the Java Development Kit (JDK) if required.
5. Run the relevant class containing the `main()` method.

*Exact run instructions may vary by application.*

## 🎯 Purpose

This project demonstrates practice with Java desktop GUI development, event handling, and small application design.
